# 《马力欧卡丁车DS》汉化补丁

## 基本说明

本项目是对 Nintendo DS 游戏《马力欧卡丁车DS》（<span lang="ja">マリオカートDS</span>）的简体中文本地化。

译名以最新的任天堂官方中文翻译为准，部分简繁不一致的译名参考任天堂译名习惯选取繁体中文译名。

## 汉化名单

- 技术：Xzonn、洗涤子、卧看微尘
- 翻译：无敌阿尔宙斯
- 美工：扭TYPE-小光
- 测试：库帕二世
